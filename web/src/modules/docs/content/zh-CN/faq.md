# 常见问题

## 看不到某个菜单

左侧菜单只显示当前账号有权限打开的页面。请管理员在角色上授予对应的页面权限，见[访问控制](/help/docs/access-control)。

## Playground 里显示「还未部署模型」

[推理服务](/inferences) 里还没有任何部署，先[部署](/help/docs/deploy)一个。

## Playground 里的模型是灰色的

部署已经存在，但还不能对话，灰色条目下方写明了原因：

- **未开启网关路由**：部署时没有开启「发布路由」，这个模型只能在集群内调用。升级该服务并开启路由。
- **路由尚未发布到网关**：路由刚创建，网关还没有加载，稍等片刻。
- **路由暂无就绪实例**：模型还在加载，或实例异常，见下一节。

## 推理服务一直是「加载中」

大模型冷启动加载权重需要 20–40 分钟，属于正常现象。超过 1 小时会变成「未就绪」，这时到服务详情的 **实例**、**事件**、**日志** 标签页排查，常见原因：

- GPU 资源不足，Pod 无法调度——到[节点](/inferences/nodes)确认空闲 GPU；
- 镜像或模型权重拉取失败——看事件和日志。

## 部署、升级按钮是灰色的

提示「这个 swissd 是只读的」：集群上的 swissd 没有开启部署权限，请运维在 swiss 配置里打开 `allowDeploy`。

提示「没有纳管计划的 release 不能在这里升级」：这个服务不是通过 swiss 部署的，只能查看。

## Playground 提示网关错误

| 提示 | 处理 |
|---|---|
| 没有配置 llm 后端 | console 安装时没有接入推理网关，需要运维在 chart 里配置 `playground.gateway` |
| 网关拒绝了凭据 | 网关密钥不对，检查站点配置里入口鉴权引用的 Secret |
| 没有 llm 后端的权限 | 角色需要在 `backends/llm` 上有 get 和 create 权限 |
| 网关不可达 | 网关地址没有解析出来或服务不可用，联系运维 |

## 程序调用返回 401

API 密钥缺失、写错、过期或已被删除。到 [API 密钥](/router/api-keys) 确认密钥状态，必要时重新创建。

## 忘记密码

请管理员处理。登录后可以随时在右上角头像菜单里修改密码。
